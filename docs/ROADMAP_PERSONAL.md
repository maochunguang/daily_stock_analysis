# 个人扩展路线图

> 以**个人专业投资者**为基准（A 股股票、基金，ETF 期权后续），不是机构级
> OMS/多租户平台。状态：`todo` / `doing` / `done` / `blocked`。
> 每项完成后必须同步 `docs/USER_GUIDE_PERSONAL.md` 和
> `docs/CHANGELOG_PERSONAL.md`。

| 项目 | 值 |
|---|---|
| 基线 | 上游 `c820915` + 个人层 `0.1.0` |
| 最后更新 | 2026-11-16 |
| 排序原则 | 先让结果可信，再谈策略和体验 |

## 0. 优先级定义

| 级别 | 含义 |
|---|---|
| **P0** | 不做会得出错误结论或无法日常使用 |
| **P1** | 影响研究深度、复盘效率 |
| **P2** | 基金能力 |
| **P3** | 期权能力（等账户开通） |
| **P4** | 实盘执行（最后做，先模拟盘） |

## 8. 建议执行顺序

1. **RM-01 ~ RM-04**（本轮）：复权、状态、日历、跨源校验。
2. **RM-05 ~ RM-06**：定时增量、费用与分红。
3. **RM-07 ~ RM-09**：策略执行器、指标运行面、参数化回测。
4. **RM-12 ~ RM-14**：交易日志、复盘报告、告警。
5. **RM-16 ~ RM-19**：基金净值、跟踪误差、申赎、ETF 轮动。
6. **RM-20 ~ RM-23**：期权。
7. **RM-24 ~ RM-26**：QMT 实盘闭环（必须先模拟盘）。

## 9. 明确不做

- 机构级多租户、RBAC、OMS/EMS。
- 全量 VaR 平台、实时风控中台。
- tick 级回测与高频执行。
- 对外提供投资建议或代客理财。
